# Megu3D — PRD

Версия 0.1 · 2026-08-13 · draft M0
Связанное: [assumptions](./assumptions.md) · [architecture](./02-architecture.md) · [roadmap](./03-roadmap.md) · [ui-architecture](./04-ui-architecture.md)

## 1. Видение

Megu3D — профессиональный Windows-пакет полного цикла 3D-производства, в котором интерфейс не мешает работать.

Существующие DCC дают либо силу без ясности (перегруженный, исторически наслоившийся UI), либо ясность без силы (простые редакторы без пайплайна). Megu3D целится в оба качества: контекстные workspaces, ядро на Rust как единственный источник истины, предсказуемая производительность и нерушимые базовые гарантии — undo/redo, сохранение, импорт/экспорт.

Одной фразой: «полный цикл от примитива до финального кадра — в чистом, быстром, модульном приложении для Windows».

## 2. Проблемы и ответы

| Проблема | Ответ Megu3D |
|---|---|
| Новичок теряется: тысячи элементов UI сразу | контекстные workspaces, прогрессивное раскрытие, advanced скрыт |
| Профи тратит время на поиск команд | command palette с fuzzy-поиском по командам, настройкам, ассетам |
| Пайплайн рвётся на импорте/экспорте | импорт/экспорт — тестируемое ядро с round-trip тестами, а не плагин «на потом» |
| Потеря работы при краше | atomic save, autosave 5 мин, `.bak`, версионируемая схема с миграциями |
| Тормоза на средних сценах | ядро на Rust, wgpu-рендер, явные бюджеты производительности как критерии приёмки |
| Расширяемость прикручена сбоку | команды, IPC и плагины — часть архитектуры с M1 |

## 3. Персоны

- **Инди-generalist.** Ассеты для игр и рендеры на заказ, работает один. Нужно: быстрый viewport, моделирование, UV, материалы, экспорт glTF/FBX. Успех: собрал ассет и выдал экспорт без чтения мануала.
- **Архитектурный визуализатор.** Планировки, интерьеры, свет, финальные кадры. Нужно: точные метры, snapping, measure, HDRI, path tracer, композитинг.
- **Технический художник small studio.** Скрипты, батчи, интеграция в пайплайн. Нужно: типизированные API, аддоны, детерминированный IO, CLI.
- **Учащийся.** Нужно: понятный старт, RU-интерфейс, подсказки, безопасный undo. Успех: за один вечер первая сцена и рендер.

Anti-persona для v1: крупная студия с USD-пайплайном и render farm; пользователи macOS/Linux; команды, которым нужна реалтайм-коллаборация.

## 4. Ключевые сценарии

1. Первый запуск: Home → создать проект → добавить куб → покрутить камеру, меньше минуты без мануала.
2. Ассет: примитив → Edit Mode → правки → модификаторы → материал → экспорт glTF.
3. Интерьер: импорт геометрии → реальные метры → свет и HDRI → камера → рендер.
4. Анимация: parent-chain или риг → keyframes → правка кривых → превью.
5. Восстановление: краш → при запуске предложено восстановить autosave → работа не потеряна.
6. Расширение: аддон появляется как панель и набор команд, не ломая ядро.

## 5. Scope по приоритетам

Приоритеты фиксируют порядок, а не сроки. Сроки — в [roadmap](./03-roadmap.md).

### P0 / MVP

| Модуль | Требование |
|---|---|
| Shell | окно Tauri, тёмная тема, HiDPI, RU/EN, persist размера и позиции |
| Layout | dockable-панели, split-дерево, workspace switcher, presets, reset layout |
| Command palette | fuzzy-поиск команд и настроек, недавние, показ хоткеев |
| Outliner | иерархия, выбор, переименование, видимость, drag-parent |
| Properties | контекстные свойства: transform, mesh info, material, light |
| Viewport | realtime PBR, grid, orbit/pan/zoom, frame selected, shading modes |
| Objects | примитивы: plane, cube, sphere, cylinder, cone, torus, empty, camera, light |
| Selection | click, box-select, add/toggle, outline выделения |
| Transform | Move/Rotate/Scale гизмо, числовой ввод, оси и плоскости, local/global |
| Modes | Object Mode + базовый Edit Mode (vertex/edge/face, move, delete, extrude) |
| History | undo/redo 64 шага, видимая история операций |
| Project IO | save/load `.megu3d`, autosave 5 мин, recovery-диалог |
| Interop | импорт/экспорт OBJ и glTF 2.0 (.gltf/.glb) |
| Look | базовые материалы metallic-roughness; свет: sun, point, spot, area |
| Preferences | темы, хоткеи, единицы, язык, autosave, GPU |

**Definition of Done для MVP:** пользователь создаёт сцену с нуля, редактирует геометрию, назначает материалы и свет, сохраняет и снова открывает проект, экспортирует glTF — и ни один из этих путей не теряет данные.

### P1 — профессиональный минимум
Расширенное моделирование (loop cut, bevel, inset, knife, bridge, merge, normals) · модификаторы Array/Mirror/Subdivision Surface · snapping и measure · UV unwrap и UV-редактор · texture painting · node material editor · HDRI-окружение · timeline, keyframes, graph editor · базовый rigging · FBX, STL.

### P2 — сила
Geometry Nodes · sculpting · auto-rig · симуляции: rigid, soft, cloth, hair, прототип fluid/smoke/fire · path tracer · texture baking · compositor · 2D/3D hybrid drawing (аналог Grease Pencil) · аддоны: architecture, trees, node assistant, mesh utilities.

### P3 — пайплайн
Полноценный Video Sequence Editor · продвинутый композитинг (трекинг, ротоскоп, стабилизация) · scripting sandbox · render farm hooks · pipeline tools (библиотеки ассетов, версии, publish/collect).

## 6. Нефункциональные требования

| Категория | Требование |
|---|---|
| Производительность | бюджеты `P-60…P-66` из assumptions — часть критериев приёмки, проверяются бенчами в CI |
| Надёжность | ни одна операция не теряет данные; save атомарен; краш не портит проект; recovery работает |
| Отзывчивость | UI-поток не блокируется дольше 100 ms; всё тяжёлое — с прогрессом и отменой |
| Совместимость | Windows 10 21H2+/11 x64, DX12 или Vulkan 1.2; понятное сообщение на неподдерживаемом GPU |
| Доступность | полная клавиатурная навигация, фокус-индикаторы, контраст текста ≥ 4.5:1, масштаб UI 80–200% |
| Локализация | RU/EN во всём UI, включая ошибки; ни одной hardcoded-строки в компонентах |
| Приватность | нет телеметрии по умолчанию, нет сетевых запросов без действия пользователя |
| Наблюдаемость | структурные логи с ротацией, «Copy diagnostics» в один клик |
| Расширяемость | плагины работают только через публичные команды и события |
| Совместимость файлов | старые `.megu3d` открываются через миграции; ломающие изменения только с мажорной `schemaVersion` |

## 7. Метрики успеха v1

| Метрика | Цель |
|---|---|
| Time-to-first-cube (новый пользователь) | < 60 s без документации |
| Time-to-first-render | < 10 мин |
| Доля сессий без краша | > 99% |
| Подтверждённые потери данных на 1000 сессий | 0 |
| Round-trip glTF без визуальных потерь | 100% на тестовом наборе |
| Соблюдение бюджетов производительности в CI | 100% гейтов зелёные |

## 8. Риски продукта

| Риск | Митигация |
|---|---|
| Огромный scope полного цикла | строгие вертикальные срезы, MVP-first, приоритеты не смешиваются |
| Конкуренция со зрелым бесплатным DCC | ставка на чистый UX, скорость и предсказуемость, а не на копирование фич |
| Производительность webview-UI на тяжёлых панелях | тяжёлое — в native viewport, списки виртуализированы, сцена не живёт в React |
| Проприетарные форматы (FBX) | glTF/OBJ как основа, FBX — документированное ограниченное подмножество |
| Сложность симуляций и path tracing | сначала референсные реализации, затем оптимизация в C++ kernels |
| Ожидания «как в другом пакете» по хоткеям | keymap-пресеты и полностью переназначаемые хоткеи |

## 9. Глоссарий

**Workspace** — предустановленный набор панелей под задачу. **Panel** — область UI с одной ответственностью. **Intent** — запрос UI на изменение сцены. **Command** — атомарная обратимая единица изменения состояния в ядре. **Transaction** — группа команд, отменяемая одним undo. **Patch/Delta** — минимальное описание изменения для undo и синхронизации UI.
